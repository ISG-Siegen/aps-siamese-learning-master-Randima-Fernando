# Algorithm Performance Space (APS) and Meta-Features

This repository contains the codebase and datasets used for my thesis, focusing on mapping dataset meta-features to an Algorithm Performance Space (APS). The project utilizes a Siamese Neural Network with Squeeze-and-Excitation attention to learn embeddings, alongside various baseline models for comparison. Training and validation rely on Leave-One-Out Cross-Validation (LOOCV).

## Directory Structure

*   **`/APS_Data`**: Contains `APS_Complete.csv`, the complete Algorithm Performance Space datasets used in the experiments.
*   **`/baseline_results`**: Contains CSV files with the prediction errors (Mean Absolute Error - MAE) generated by the baseline models.
*   **`/Dataset_Meta_Features`**: Houses the extracted raw meta-features in three distinct configurations: `45_Dataset_Meta_features.csv`, `75_Dataset_Meta_features.csv`, and `Dataset_Meta_features.csv` (137 features).
*   **`/Meta_feature_extraction`**: Includes the raw datasets and the `extract_meta_features.py` script used to generate the CSV files in the `Dataset_Meta_Features` folder.
*   **`/training_results`**: Contains results from the neural network training runs, separated into folders based on the meta-feature configuration (e.g., `45_meta_features`). Includes `test_results_num.csv` (final MAE per fold) and `validation_num.csv` (MAE tracked every two epochs).
*   **`/weights`**: Stores the PyTorch model weights saved after training under each meta-feature configuration.

## Core Modules

### Data Handling

**`aps_data_handling.py`**
The main utility for loading and formatting APS and meta-feature data. 
*   **`FetchAPSFeatureData`**: Fetches the required performance metric and meta-feature configuration (45, 75, or 137). Returns pandas dataframes for both APS and meta-features.
*   **`APSFeatureDataset`**: Converts pandas dataframes into a PyTorch-compatible dataset. Its `__getitem__` method returns `(Anc, Pos, dist)`—two meta-feature vectors and their ground-truth APS distance.
*   **`leave_one_out()`**: A utility function that removes data for a specified index to support the LOOCV pipeline.

### Model Architecture

**`network_blocks.py`**
Defines the building blocks of the Siamese Neural Network architecture and the custom loss function.
*   **`FeatureAttention`**: An input-level Squeeze and Excitation Attention block.
*   **`EmbeddingNet`**: Defines a single branch of the Siamese network.
*   **`SiameseNet`**: Wraps the `EmbeddingNet` to create the dual-branch architecture.
*   **`stress_loss`**: The core loss function based on Sammon Stress. It computes the distance between network embeddings (`z1`, `z2`) and penalizes deviations from the true high-dimensional APS distance.
*   **`train`**: The primary PyTorch training loop.

### Training & Validation Pipelines

**`auto_train.py`**
The orchestrator script for model training. It executes LOOCV by training 66 distinct models per run (each fold leaving out one dataset for validation). The entire 66-fold process is repeated 10 times to calculate average performance metrics.

**`validation.py`**
Handles the evaluation of left-out folds during training. 
*   **`test_left_out()`**: Loads model weights, generates an embedding for the left-out dataset, calculates distances to all other embeddings, compares them against the ground-truth APS distances, and returns the MAE.

### Predictions & Baselines

**`model_prediction.py`**
Generates final APS vector predictions for left-out datasets using the fully trained Siamese models. It employs two distinct prediction methods:
*   **Latent Space Nearest Neighbor**: Finds the nearest dataset in the learned latent space and adopts its APS vector.
*   **Trilateration**: Uses the distances to the nearest datasets in the latent space as anchors to solve a least-squares problem, predicting the target APS vector.

**`baseline.py`**
Runs identical LOOCV loops using standard machine learning baselines for comparative analysis. Models include Global Mean, K-Means, KNN, Random Forest, and XGBoost. The script outputs the MAE between predicted and actual APS vectors, as well as the vector distances, saving them to `/baseline_results`.

### Feature Extraction

**`/Meta_feature_extraction/extract_meta_features.py`**
The primary script for extracting raw meta-features from source datasets. Detailed comments within the script document the extraction methodology for every specific meta-feature.
